# WellbeingX

Digital wellbeing & productivity platform focused on helping users understand, improve, and optimize their daily habits.

## Overview

WellbeingX is a privacy-first Android application that analyzes device usage patterns and transforms raw behavioral data into meaningful insights.

The app helps users build healthier digital habits, improve focus, track productivity, and understand how their daily routines evolve over time.

Unlike traditional screen-time trackers, WellbeingX focuses on behavioral intelligence, trend analysis, and long-term habit improvement.

## Features

### Digital Wellbeing Analytics
- Screen time tracking
- App usage analysis
- Unlock frequency monitoring
- Daily and weekly trends
- Productivity insights

### Sleep Analysis
- Sleep window detection
- Wake-up consistency tracking
- Sleep duration estimation
- Sleep quality indicators

### Focus & Productivity
- Focus sessions
- Deep work tracking
- Productivity scoring
- Habit consistency monitoring

### Behavioral Intelligence
- Daily wellbeing score
- Trend detection
- Habit pattern analysis
- Personal insights engine

### Privacy First
- Offline-first architecture
- Local data processing
- No unnecessary cloud dependency
- User-controlled data
